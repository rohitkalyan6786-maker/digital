# Nexa Digital Agency Website

## Files

- `dist/index.html` — website structure
- `dist/style.css` — complete design and responsive CSS
- `dist/script.js` — video control, navbar and form interaction
- `dist/assets/images/` — local website images
- `dist/assets/videos/` — local MP4 video

## Run locally

Open `dist/index.html` in a browser or use VS Code Live Server.

## Publish on GitHub Pages

1. Upload the **contents inside `dist`** to the root of your GitHub repository.
2. Keep the `assets` folder structure unchanged.
3. Go to repository **Settings → Pages**.
4. Select **Deploy from a branch**, choose `main` and `/root`, then Save.

The contact form is a frontend demonstration. Connect Formspree or a backend endpoint to receive real enquiries.
